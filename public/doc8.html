1Mkke nedir?

Mkke, Parax'ın bot servisidir: bot kaydı, jeton dağıtımı ve botların sohbetle konuşmasını sağlayan uçların tamamı. Geliştirici tarafında Mkke-SDK deposu, kullanıcı tarafında DevPortal (bot paneli) bu servisin yüzleridir.

Bot, Parax'ta özel bir hesap gibidir: bir Client ID'si ve gizli bir jetonu vardır. Jetonla giriş yapan program mesaj okur, mesaj yazar, kanal listeler ve canlı olayları dinler.

2Hangi diller destekleniyor?

Şu an yalnızca JavaScript + TypeScript ile bot yazılabilir (Mkke-SDK). Python ve Java iskeletleri hazır ama çalışmıyor; bu dillerin desteği platformla birlikte gelecek.

JavaScript bilmiyorsan üzülme: Parax ekibi kopyala-çalıştır şablonları yayınlayacak (8. bölüm).

3Jeton alma (DevPortal)

  1. Giriş yap ve bot panelini aç.
  2. Yeni Bot Oluştur: ad, açıklama ve kapsamları seç.
  3. Jetonu kopyala: parax_bot_... ile başlayan jeton bir kez gösterilir.
  4. Jetonu kodunun içine, tercihen ortam değişkenine koy.
Jetonu kimseyle paylaşma, herkese açık depoya koyma. Sızdıysa panelden Yenile'ye bas; eskisi anında ölür.

4Botun konuşması: REST

Uçİş
POST /api/messagesMesaj gönder (send kapsamı)
GET /api/servers/:code/channelsKanal listele (read kapsamı)
POST /api/auth/loginE-posta+şifreyle kullanıcı girişi

Tüm isteklerde başlık aynıdır: Authorization: Bearer parax_bot_... Hatalar Oddiss koduyla döner (örn. 141 jeton geçersiz, 142 kapsam eksik).

5Botun dinlemesi: ağ geçidi

Botun, yeni mesajlardan anında haberdar olur: wss://...?token=parax_bot_... adresine bağlanır, ready alır, sonra her mesajda messageCreate olayı gelir. Bağlantı koparsa SDK 5 saniyede bir yeniden dener.

6Kapsamlar (scopes)

Jeton, seçtiğin kapsamlar kadar yetkilidir: read (oku), send (yaz), kick, ban, connect, speak, manage_roles, manage_channels. Kapsam dışı istek 142 koduyla reddedilir.

En az yetki ilkesi: botuna işini görecek en dar kapsamları ver.

7Hızlı başlangıç kodu

const { Bot } = require("parax-bot-sdk");
const bot = new Bot(process.env.PARAX_BOT_TOKEN, {
  wsUrl: "wss://parax-vqqb.onrender.com"
});

bot.on("ready", () => console.log("Mkke çevrimiçi!"));
bot.on("messageCreate", async (msg) => {
  if (msg.content === "!ping") await msg.reply("pong!");
});

bot.connectGateway();

8Şablonlar ve sırada ne var?

Parax ekibi yeni başlayanlar için hazır şablonlar yayınlayacak: karşılama botu, moderasyon botu, müzik botu iskeleti ve tek-tık dağıtım örnekleri. Ayrıca Python/Java SDK'ları ve bot marketi (bot dizini) yolda. Duyurular Sürüm Notları'nda olacak.

1What is Mkke?

Mkke is Parax's bot service: bot registration, token issuance, and every endpoint bots use to talk to chat. Developers meet it as the Mkke-SDK repo; users meet it as the DevPortal (bot panel).

A bot is like a special Parax account: it has a Client ID and a secret token. A program logging in with the token reads messages, writes messages, lists channels, and listens to live events.

2Which languages are supported?

Right now bots can only be written in JavaScript + TypeScript (Mkke-SDK). Python and Java skeletons exist but don't run; their support lands with the platform.

Don't know JavaScript? Don't worry: the Parax team will publish copy-paste templates (section 8).

3Getting a token (DevPortal)

  1. Log in and open the bot panel.
  2. Create a bot: name, description, scopes.
  3. Copy the token: the parax_bot_... token is shown once.
  4. Put it in your code, preferably an environment variable.
Never share the token or commit it to a public repo. If it leaks, press Regenerate in the panel; the old one dies instantly.

4Bot talks: REST

EndpointJob
POST /api/messagesSend a message (send scope)
GET /api/servers/:code/channelsList channels (read scope)
POST /api/auth/loginEmail+password user login

Every request carries the same header: Authorization: Bearer parax_bot_... Errors come back with Oddiss codes (e.g. 141 invalid token, 142 missing scope).

5Bot listens: gateway

The bot learns about new messages instantly: connect to wss://...?token=parax_bot_..., receive ready, then a messageCreate event per message. If the connection drops, the SDK retries every 5 seconds.

6Scopes

The token is only as powerful as the scopes you picked: read, send, kick, ban, connect, speak, manage_roles, manage_channels. Out-of-scope requests are refused with code 142.

Least privilege: give your bot the narrowest scopes that do its job.

7Quickstart code

const { Bot } = require("parax-bot-sdk");
const bot = new Bot(process.env.PARAX_BOT_TOKEN, {
  wsUrl: "wss://parax-vqqb.onrender.com"
});

bot.on("ready", () => console.log("Mkke online!"));
bot.on("messageCreate", async (msg) => {
  if (msg.content === "!ping") await msg.reply("pong!");
});

bot.connectGateway();

8Templates and what's next?

The Parax team will publish starter templates: welcome bot, moderation bot, music bot skeleton, and one-click deploy samples. Python/Java SDKs and a bot directory are also on the way. Announcements land in Release Notes.
