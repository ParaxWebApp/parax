1Perax Translator nedir?

Perax Translator, Parax sohbetinin içine gömülü tek tıkla çeviri servisidir. Her mesajın yanında duran Translate düğmesine basarsın, mesaj senin diline çevrilir ve yanında küçük bir (translated) rozeti belirir. Orijinal mesaj kaybolmaz; çeviri onun yerinde, geçici olarak gösterilir.

Teknik olarak bağımsız bir mikroservistir: çeviri motoru olarak açık kaynak LibreTranslate kullanır, Parax ana uygulamasından ayrı çalışır. Yani çeviri servisi bakımda olsa bile sohbetin aksamaz.

Şu an varsayılan hedef dil Türkçedir; dil tercihi kullanıcı bazında ayarlanabilir, İngilizce topluluklar İngilizce kullanır.

2Neden yapıldı?

  • İki dilli topluluk: Parax'ta Türkçe ve İngilizce konuşanlar aynı sunucularda. Herkesin birbirini anlaması için çevirinin sohbetin içinde olması gerekiyordu; sekmeler arası kopyala-yapıştır kimseye uymaz.
  • Hız: Mesajı seç, düğmeye bas, oku. Üç saniyelik iş.
  • Bağımsızlık: Büyük çeviri API'lerine doğrudan bağımlı olmak yerine arada kendi servisimiz var; motor değişse bile düğme aynı kalır.

3Nasıl çalışır?

  1. Düğmeye basarsın: Mesajdaki Translate'e tıkladığında düğme önce "Translating..." olur.
  2. İstek gider: Uygulama, mesaj metnini ve hedef dilini çeviri servisine (/api/translate) gönderir.
  3. Motor çevirir: Servis metni LibreTranslate motoruna verir; kaynak dil otomatik algılanır, hedef dile çevrilir.
  4. Sonuç gelir: Çevrilen metin mesajın yerinde, yanında (translated) rozetiyle gösterilir.

Kaynak dili seçmene gerek yoktur; motor "bu mesaj hangi dilde?" sorusunu kendisi cevaplar. Çeviri yalnızca sana gösterilir; başkaları mesajı kendi dilinde görmeye devam eder.

4Nasıl kullanılır?

  1. Dilini ayarla: Çevirilerin hangi dile yapılacağını profil/uygulama dil tercihinden seç (varsayılan: Türkçe).
  2. Düğmeye bas: Anlamadığın mesajın yanındaki Translate'e tıkla.
  3. Oku: Çeviri mesajın yerinde belirir. Orijinali görmek istersen sayfayı yenilemen yeterli; kayıtlı mesaj değişmez.
Uzun mesajlarda çeviri birkaç saniye sürebilir; düğme "Translating..." yazarken bekle, tekrar tekrar basma.

5Gizlilik: mesajlarım nereye gidiyor?

Dürüst cevap:

  • Çevirdiğin metin çeviri servisine ve oradan çeviri motoruna (LibreTranslate) gider. Çeviri ancak metin motora ulaşırsa yapılabilir; bu, her çeviri servisinin doğasıdır.
  • Servis metin saklamaz: Çeviri isteği yanıtlanaıp kapanır; mesajların çeviri için ayrı bir veritabanında tutulmaz. Zaten sohbette yazdığın mesaj sunucuda kayıtlıdır; çeviri buna yeni bir kopya eklemez.
  • Hassas bilgi çevirme: Şifre, özel adres, banka bilgisi gibi şeyleri çeviriye gönderme. Bu kural her çeviri aracı için geçerlidir.
Özel (DM) mesajların da çevirisi aynı yoldan geçer. Gerçekten gizli kalması gereken bir şeyi çevirme; orijinal dilde okumaya çalış.

7Sık sorulan sorular

  • Çeviri kalıcı mı? Hayır. Yalnızca senin ekranında, geçici olarak gösterilir. Kayıtlı mesaj değişmez.
  • Herkes aynı çeviriyi mi görür? Hayır. Herkes kendi dil tercihine göre çevirir; kimse kimsenin çevirisini görmez.
  • Kaynak dili seçebilir miyim? Gerek yok, otomatik algılanır.
  • Hangi diller var? Motorun desteklediği tüm diller; hedef dil, dil tercihine göre ayarlanır.
  • Çeviri yanlış, düzeltebilir miyim? Şu an elle düzeltme yok; orijinal metne bakman yeterli. Geri bildirimlerin motor seçimini iyileştirir.

1What is Perax Translator?

Perax Translator is the one-click translation service built into Parax chat. You press the Translate button next to any message, it renders in your language with a small (translated) badge. The original message is never lost; the translation shows in its place, temporarily.

Technically it is an independent microservice: it uses the open-source LibreTranslate engine and runs separately from the main Parax app. So even if the translation service is down, your chat keeps working.

The default target language is currently Turkish; the preference is per-user, so English communities use English.

2Why was it built?

  • A bilingual community: Turkish and English speakers share the same servers on Parax. Everyone needed to understand each other inside the chat; copy-pasting between tabs works for nobody.
  • Speed: Select the message, press the button, read. A three-second job.
  • Independence: Instead of depending directly on big translation APIs, our own service sits in between; the button stays the same even if the engine changes.

3How does it work?

  1. You press: Clicking Translate on a message first flips the button to "Translating...".
  2. Request goes out: The app sends the message text and target language to the translation service (/api/translate).
  3. Engine translates: The service hands the text to the LibreTranslate engine; source language is auto-detected and translated to the target.
  4. Result returns: The translated text appears in place of the message with a (translated) badge.

You never pick a source language; the engine answers "what language is this message?" itself. The translation shows only to you; everyone else keeps seeing the message in their own language.

4How to use it?

  1. Set your language: Choose which language translations target in your profile/app language preference (default: Turkish).
  2. Press the button: Click Translate next to any message you don't understand.
  3. Read: The translation appears in place. To see the original again, just refresh; the stored message is untouched.
Long messages can take a few seconds; while the button says "Translating...", wait instead of pressing repeatedly.

5Privacy: where do my messages go?

The honest answer:

  • Translated text travels to the translation service and on to the translation engine (LibreTranslate). Translation is only possible if the text reaches the engine; that's the nature of every translation service.
  • The service stores no text: A translation request is answered and closed; messages aren't kept in a separate database for translation. What you wrote in chat is already stored on the server; translation adds no new copy.
  • Don't translate secrets: Never send passwords, private addresses, or banking details to translation. This rule holds for every translation tool.
Private (DM) messages travel the same path when translated. If something must truly stay secret, don't translate it; read it in the original language.

6Limits and fallback mode

ConditionWhat you seeWhat to do
Engine busyTranslation lags, or original text with a [Translated (tr)] prefixThat's fallback mode; retry in a few minutes.
Nonsense translationSlang, game terms, abbreviations mistranslatedNormal; machine translation is weak on idioms. Check the original.
No buttonTranslate missing on a messageRefresh; if it persists, check Oddiss.

Fallback mode hides no failure: if the engine doesn't answer, the service says so openly (engine: fallback) and preserves the original text. A made-up translation is never shown.

7FAQ

  • Is translation permanent? No. It shows only on your screen, temporarily. The stored message never changes.
  • Does everyone see the same translation? No. Everyone translates to their own language preference; nobody sees anyone else's translation.
  • Can I pick the source language? No need — it's auto-detected.
  • Which languages exist? All languages the engine supports; the target follows your language preference.
  • A translation is wrong, can I fix it? No manual correction yet; the original text is enough. Your feedback improves engine choice.
